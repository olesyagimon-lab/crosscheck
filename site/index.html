A few answers
before you start

Which documents can I use?

A one-page text-based PDF with product names, SKU codes and ordered quantities. Up to five product types.

What if a label is hidden?

Take a close-up of the label, keeping the unit identifier visible. Add the photo, or replace an earlier shot if you have already uploaded three.

Can I try it without my own files?

Yes. Select “Try an example” to load a matching PDF and an AI-generated sample photo. The local reader processes these files using the same steps as your own files. There are no prepared recognition answers.

Where are my files sent?

Your PDF and photos are read locally in this browser. They are not uploaded to a recognition service. Files are kept only in this tab. The reader and language files are included with the site; no paid API is used.
